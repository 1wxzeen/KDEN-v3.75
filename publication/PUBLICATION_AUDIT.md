# Public release review — October 23, 2026

## Purpose and boundary

This is a curated source-and-evidence snapshot for the standalone
`1wxzeen/KDEN-v3.75` repository. It was assembled in a new directory, not by
repurposing the original working checkout. Frozen acquisition, weather, truth,
and prefit releases were not rewritten or reattested for publication.

The [public manifest](PUBLIC_MANIFEST.json) enumerates shipped files, their
public hashes, original source hashes where applicable, and public edits.
The manifest excludes itself from its hash list to avoid a circular hash.
Original freeze records remain historical metadata: their omitted complete
inputs are not magically supplied by this reduced public checkout.

## Selection and editorial review

- Included project implementation and tests, versioned scientific contracts,
  selected aggregate reports, four front-page figures, and their supporting
  aggregate inputs/renderers.
- Excluded weather/truth tables, individual predictions, raw climate reports,
  pretrained weights, environments, private Git history, credentials, backups,
  and sibling/previous codebases. No local Git history was inherited.
- Converted five owner-selected research Word documents to Markdown reading
  editions, preserving source filenames/hashes, tables, math, citations, and
  historical agent-directed wording. Conversion emitted no warnings. The
  original Office/PDF files and their personal metadata are not distributed.
- Reviewed the 16 extracted research images for visible individual reserved
  outcomes and personal metadata. One reserved-period correction-example row
  in the older scientific record was withheld from its public reading edition.
  The historical truth-layer PDF is not bundled; a clearly identified public
  guide describes the adopted audit instead.
- Made personal filesystem references portable in public documentation and one
  historical config-building helper. No model/scoring parameters were changed.
  Public README/index/status notices distinguish historical plans from results.
- Kept the disclosed selection-timing violation and sensitivity, incomplete
  pretrained-tabular replay, differing scoring conventions, and absence of a
  profitability claim. Negative findings were not removed.
- Used MIT for original project materials, with third-party boundaries in
  [NOTICE.md](../NOTICE.md); no external model weights or literature collection
  is redistributed.

## Bounded checks performed

- Standard-library quickstart over bundled aggregates: passed.
- Public figure-input tests: 20 passed.
- Atomic publication and mocked HTTP-range tests: five passed.
- Successor timing-boundary tests: eight passed.
- Real issue-grid demo: 57 ordinary-day issues and 53 spring-forward issues.
- Three statistical figure renderers: completed from bundled saved summaries,
  with no model fitting, network requests, or individual label/prediction reads.
- Python sources parsed, local Markdown link targets checked, public file hashes
  checked, and explicit excluded artifact classes screened by
  [check_publication.py](../tools/check_publication.py).
- Text screening covered common credential markers, private keys, and personal
  home paths; selected embedded-image and document conversion metadata were
  reviewed separately. No matching credentials remained in the delivered set.
- Original source hashes were checked while assembling the manifest. Public
  transformations have separate hashes rather than pretending to preserve the
  source's original scientific acceptance hash.

The core checks used existing installed dependencies read-only, pointed at the
public source tree. They were not a clean installation of every historical ML
environment. No long full-archive acceptance, reacquisition, training, model
replay, or reserved-outcome audit was run for publication.

## Limits

Pattern screening is not a mathematical guarantee against every possible
secret. Local link checks do not establish the correctness or current
availability of external websites. These checks do not independently repeat
the scientific studies or certify market suitability. Figure reproduction is
replotting saved evidence, not a new evaluation. For precise public scope,
read [DATA_AVAILABILITY.md](../DATA_AVAILABILITY.md) and
[REPRODUCIBILITY.md](../REPRODUCIBILITY.md).
